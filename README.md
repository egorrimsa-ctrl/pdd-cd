# Тренажёр ПДД C·D

Билеты ПДД категорий C и D: программа на 14 дней, закономерности, сложные темы, тренировка, работа над ошибками и экзамен как в ГИБДД.

Работает как приложение на iPhone и без интернета:

1. Откройте сайт этого репозитория (GitHub Pages) в Safari.
2. Дождитесь строки «Всё скачано: приложение работает без интернета».
3. «Поделиться» → «На экран „Домой“».

Прогресс хранится только на устройстве.
